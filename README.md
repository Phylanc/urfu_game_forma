# Задание 1: в проекте Unity реализовать перцептрон, который умеет производить вычисления:
`OR | дать комментарии о корректности работы:`

- Перцептрон успешно справляется с задачей обучения операции OR. Эта операция линейно разделима, поэтому веса перцептрона могут быть настроены так, чтобы корректно классифицировать входные данные. После завершения обучения модель выдает результаты, соответствующие таблице истинности. Величина ошибки после нескольких эпох обучения стремится к нулю, что подтверждает корректность работы.

`AND | дать комментарии о корректности работы:`

- Аналогично OR, функция AND также линейно разделима, что делает ее хорошо подходящей для реализации однослойным перцептроном. После обучения модель корректно различает входные данные, выдавая значения, которые совпадают с таблицей истинности. Если количество эпох обучения достаточно, а случайная инициализация весов не мешает, результат полностью соответствует ожидаемому.

`NAND | дать комментарии о корректности работы:`

- NAND, будучи обратной операцией для AND, также является линейно разделимой функцией. Перцептрон корректно обучается этой операции, так как изменение весов и смещения позволяет адаптировать модель под эту задачу. После успешного обучения модель демонстрирует стабильные результаты, которые совпадают с таблицей истинности.

`XOR | дать комментарии о корректности работы:`

- Перцептрон не может корректно обучиться функции XOR, так как эта операция нелинейно разделима. Входные данные для XOR невозможно разделить одной прямой линией в двумерном пространстве, что является фундаментальным ограничением однослойного перцептрона.

# Задание 3: Построить визуальную модель работы перцептрона на сцене Unity.

В проекте на Unity реализована увлекательная визуализация работы перцептронов с использованием двух кубов. Каждый куб выступает носителем объекта перцептрона, к которому можно привязать конкретный номер входа через инспектор (нумерация начинается с 0). По мере взаимодействия кубы реагируют на изменения входных данных, меняя цвет: белый сигнализирует о значении 0, а черный — о значении 1.
